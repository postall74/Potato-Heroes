# 🥔 Potato Heroes — Brotato-like на Unity 6

Roguelike-арена в духе **Brotato**, но со своими персонажами и мобами:
вы — картофельный герой, защищающий огород от волн слизи, летучих мышей и призраков.

## Быстрый старт
1. Установите **Unity 6 (6000.x)**, откройте эту папку как проект (Unity Hub → Add project).
   Unity сам доустановит пакеты из `Packages/manifest.json` (модуль 2D).
2. Дождитесь импорта ассетов (скрипт `Assets/Editor/ProjectSetup.cs` сам настроит спрайты и слои).
3. Откройте `Assets/Scenes/SampleScene.unity` → **Play**.

> Если PNG-спрайтов вдруг нет — перегенерируйте их:
> `python3 Assets/Sprites/generate_sprites.py` (нужен Pillow: `pip install pillow`).

## Управление
| Клавиши | Действие |
|---|---|
| WASD / стрелки | движение |
| мышь | направление взгляда; **ЛКМ (зажат)** — стрельба по курсору |
| автоатака | оружие само стреляет по ближайшему врагу (как в Brotato) |
| Enter / Space | продолжить после волны |

## Игровой цикл
- **10 волн** по 30 секунд, последняя — волна босса **«Король Желе»** 👑.
- Враги: Зелёная слизь, Красная ярость, Ледяная слизь, Летучая мышь, Призрак огорода + свита босса.
- С убитых падают **кристаллы опыта** (магнитятся к игроку) → повышение уровня → выбор 1 из 3 улучшений
  (Здоровье, Сила, Скорострельность, Крит, Вампиризм, +1 снаряд, Броня и т.д.).
- В конце каждой волны появляется **сундук с новым оружием**: Картофельный пистолет, Гороховый ПП,
  Тыквенный дробовик, Кукурузная винтовка, Нож «Чистый Картофель» (ближний бой), Волшебная лоза.
- Между волнами — лёгкое лечение. Победа: убить босса. Поражение: смерть — статистика и рестарт.

## Персонажи (аналоги классов Brotato со своими механиками)
- **Капитан Клубень** — +15% урона, универсал.
- **Инженер Очисток** — +15% скорости бега.
- **Медсестра Росток** — +30% ОЗ и броня, стеклянная… наоборот, танк.
- **Маг Трюфель** — +25% урона, −20% ОЗ.

## Структура
```
Assets/
 ├─ Scenes/SampleScene.unity   — пустая сцена с объектом [GAME]
 ├─ Scripts/                   — вся логика (~1500 строк C#)
 │   GameManager / Player / Enemy / Bullet / Pickups / HUD / SpriteAnimator / AssetBank ...
 ├─ Sprites/                   — pixel-art спрайт-шиты + генератор generate_sprites.py
 └─ Editor/ProjectSetup.cs     — автоконфигурация импорта и слоёв
```

Все спрайты и анимации (walk/idle/fly/pulse по 4 кадра) создаются скриптом-генератором
в стиле pixel-art и грузятся рантаймом через `AssetBank`, поэтому проект не требует ручной
расстановки префабов: мир, UI и враги строятся кодом.
